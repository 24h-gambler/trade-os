# Trade OS

**1688 사입 셀러의 랜딩 코스트 + 30일 외상 — 타겟 아키텍처**

> "셀러가 공장 PI를 올리면, **한국 도착 원가**를 확인하고, 1탭으로 **결제·통관·세무·30일 외상**까지 끝내는 B2B 무역 정산 OS."

## 문서

- [ARCHITECTURE.md](ARCHITECTURE.md) — 타겟 아키텍처, 자금 흐름, 원장, 규제 구조, 90일 MVP

## 포지셔닝

- **Corridor**: China → Korea (1688/광저우/이우)
- **Vertical**: K-beauty/액세서리 사입 셀러
- **Wedge**: 랜딩 코스트 체크아웃 + 30일 외상
- **결제**: 파트너(XTransfer/은행/VASP)를 오케스트레이션. 우리는 문서·통관·세무·신용을 소유.

## 핵심 원칙

1. 결제는 파트너, 우리는 **문서·통관·신용**을 소유한다.
2. 고객은 `USDC`, `wallet`, `gas`를 보지 않는다.
3. 문서 없는 지급은 없다.
4. 한국 법인은 크립토를 만지지 않는다.
5. 결제로 돈을 벌지 않고, **신용·SaaS**로 번다.
